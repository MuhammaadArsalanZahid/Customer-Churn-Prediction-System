# Demo video outline

Target length: 2–4 minutes.

1. Introduce yourself and the internship project.
2. Explain the churn problem and project workflow.
3. Demonstrate two different customer inputs.
4. Show churn probability, risk level, threshold and SHAP factors.
5. Upload a CSV, generate predictions and download the output.
6. Show the dashboard and actual test metrics generated by training.
7. Mention one limitation and a possible improvement.
