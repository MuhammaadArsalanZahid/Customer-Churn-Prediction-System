# Dataset

Download the public Telco Customer Churn CSV from:

https://www.kaggle.com/datasets/blastchar/telco-customer-churn

Put the CSV here:

`data/WA_Fn-UseC_-Telco-Customer-Churn.csv`

The raw dataset is not included in this repository. Check the Kaggle dataset
page and verify its current license and terms before using or redistributing it.
